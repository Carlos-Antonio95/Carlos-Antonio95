**Desenvolvedor Full Stack em formação** · Análise e Desenvolvimento de Sistemas – UNIBRA (5º período, conclusão prevista em jul/2027) · Recife/PE

No back-end uso Java e Spring Boot; no front-end, React com Vite; publico em VPS Linux com Docker. Também atuei como **Scrum Master** de uma equipe de quatro desenvolvedores.
